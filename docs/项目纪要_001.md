China Travel OS 项目纪要 001（中文版）

> 📸 **Session Archive 001** — 冻结快照，记录项目 MVP 完成时的阶段性总结。最新进度见 `项目笔记.md`。

用途：这是一份干净的人类可读项目总结，用来替代冗长且格式混乱的原始聊天记录。

一、项目当前状态

China Travel OS 网站 MVP 已经基本完成。

目前已完成的基础攻略页面包括：支付宝、微信支付、必装 Apps、VPN、eSIM、高铁、地铁与公交、共享单车、DiDi / 网约车、安全、First-Time China Checklist。

项目已经从「搭建网页」进入「建设品牌」的阶段。接下来重点不再是继续无限增加基础攻略，而是建立品牌定位、TikTok 内容系统、Checklist 转化路径和长期 Brand Bible。

二、项目使命

China Travel OS 的使命：帮助第一次来到中国的外国游客降低旅行中的不确定性（Remove uncertainty）。不是介绍中国，而是帮助用户顺利完成第一次中国自由行。

三、品牌定位

我们不是旅行社、景点网站、旅游博客或宣传账号，而是：The Operating System for First-Time Travelers to China。

四、品牌人格

像一个长期生活在中国、值得信赖的朋友，而不是导游、推销员或流量博主。

五、关键决策

Decision 001：基础攻略到 DiDi / 网约车为止，暂时停止继续扩展。避免陷入「再写一篇攻略」的无底洞。
Decision 002：进入 Route B。核心是 First-Time China Checklist / Starter Guide，而不是继续堆单篇内容。
Decision 003：Checklist 首先应该是一个网站 Hub 页面；PDF 是从它提炼出来的衍生资产，而不是先做 PDF 再做网页。
Decision 004：首页信息流保持：Hero → Anxiety → Checklist 入口 → Guides。先共情，再给路径。
Decision 005：Checklist 同时保留两个角色：Anxiety 区快捷入口给性急用户；Guide 区独立分类给愿意系统探索的用户。
Decision 006：看病 / 医疗问题很重要，但目前不作为核心 Guide 单独展开。先放入 Safety 或 Checklist 的紧急情况模块中。

六、品牌原则

Principle 001：Explain China, don't impress people with China。解释中国，而不是炫耀中国。
Principle 002：Reduce anxiety before creating excitement。先降低焦虑，再制造向往。
Principle 003：One page solves one problem。每一篇页面解决一个明确问题。
Principle 004：Every TikTok solves one problem。每一条 TikTok 也只解决一个问题。
Principle 005：Always use real experiences。尽量使用真实经历、真实场景和真实细节。
Principle 006：重要 Guide 尽量包含 TL;DR、真实案例、Common Mistakes、FAQ 和 CTA。
Principle 007：Build trust before chasing views。先建立信任，再追求播放量。

七、内容战略

真正解决的是信息差、安全感、认知反差和中国真实体验，而不是单纯介绍景点。

八、杭州战略

先把杭州做到最好，再复制到其他城市。长期深耕一个城市，比全国打卡更有品牌价值。

九、网站定位

网站不再是一堆旅游攻略的集合，而是一个面向第一次来中国的外国游客的 China Travel Operating System。

目前内容体系覆盖：网络、支付、必装 App、城市交通、城际交通、安全、Checklist。

网站的核心价值不是介绍景点，而是帮助用户理解「第一次来中国到底怎么顺利运转」。

十、首页逻辑

Hero 负责传达主张：China, made simple。

Anxiety 区负责命中用户真实恐惧：Google 能不能用、能不能付款、怎么坐火车、是否安全等。

Checklist 负责给用户快速行动路径。

Guides 负责给有耐心和求知欲的用户系统探索。

Newsletter / PDF 负责沉淀用户关系。

十一、TikTok 策略

视频格式：90% 竖屏，10% 横屏风景素材。竖屏优先服务 TikTok、YouTube Shorts、Instagram Reels 等平台。

内容不是「Amazing China」，而是「如何解决第一次来中国的真实问题」。

每条视频遵循：Hook → Problem → Show → Explain → CTA。

推荐 CTA：Need the full checklist? Link in bio。

第一条视频建议：If you are visiting China next month, do these 5 things first。内容围绕 VPN、eSIM、Alipay、Amap、DiDi。

十二、账号名与简介

首选账号名：China Travel OS。理由：与网站统一，品牌边界清晰，能承载「系统化解决第一次来中国问题」的定位。
备选账号名：China Made Simple。优点是更亲民，缺点是未来品牌边界略窄。
推荐 Bio：🇨🇳 Modern China, explained. / ✈️ First-time travel made simple. / 👇 Free China Arrival Checklist。

账号定位：不要做普通 Vlog，而是做「外国人第一次来中国的问题解决型媒体品牌」。

十三、长期内容生态

TikTok = 发现入口。
Website = 知识库。
Checklist = 转化入口。
Newsletter = 长期关系。
未来产品 / 服务 = 商业化。

整体路径：TikTok → Website → Checklist → Email → Future Products / Services。

十四、竞争优势

Content + SEO Website + Checklist + Newsletter + Community + Future Services。

十五、商业路线

TikTok → Website → Checklist → Newsletter → 数字产品 → 咨询 → 平台化服务。

十六、永远不要做什么

不要官方宣传；不要猎奇中国；不要制造对立；不要 AI 垃圾内容；不要为了流量牺牲可信度。

十七、长期维护方式

以后不再依赖原始聊天记录。聊天记录容易丢失，也会包含大量无用推导过程。

长期维护两类文档：Brand Bible 和 Session Archive。

Brand Bible 记录长期原则、定位、视觉规范、内容规范和重要决策。

Session Archive 记录每次工作完成了什么、做了什么决定、增加了什么原则、下一步做什么。

每次新会话只需要上传最新 Brand Bible 和最近 1-3 份 Session Archive，就能快速恢复项目上下文。

十八、下一阶段目标

1. 启动 TikTok 账号。
2. 最终确认品牌名、账号名和简介。
3. 制作前 10 条短视频。
4. 开始收集第一批真实用户反馈。
5. 根据真实反馈更新 Brand Bible。
6. 后续逐步完善网站实拍图片和城市页。

十九、最终愿景

China Travel OS 的目标不是成为普通中国旅游网站，而是成为最值得信任的英文品牌，帮助第一次来中国的外国游客有信心、有准备、低焦虑地完成旅行。

以后每一个重要决定都可以问一句：这是否值得写进 Brand Bible？如果答案是值得，那么它就不只是一次聊天，而是品牌长期资产的一部分。
